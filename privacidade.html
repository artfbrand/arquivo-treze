Política de Privacidade

Fábrica Arquivo Treze · última atualização: 19 de novembro de 2026

1. O que é a ferramenta

A Fábrica Arquivo Treze é um programa de uso próprio do dono do canal do YouTube "Arquivo Treze". Ele roda no computador do dono do canal e não é oferecido a outras pessoas.

2. Quais dados ela acessa

Com a autorização do dono do canal pelo login do Google, a ferramenta usa os Serviços de API do YouTube somente na conta do próprio canal, para:

  • enviar os vídeos produzidos pelo canal, com título, descrição, tags e horário de publicação (YouTube Data API);
  • enviar a legenda de cada vídeo e adicionar o vídeo às playlists do próprio canal (YouTube Data API);
  • ler o nome do canal e as estatísticas dos vídeos do próprio canal, como visualizações, curtidas, comentários, retenção e inscritos ganhos (YouTube Data API e YouTube Analytics API).

A ferramenta não acessa dados de espectadores individuais, de outros canais ou de outras contas do Google.

3. Onde os dados ficam

O token de acesso do Google e as estatísticas lidas ficam guardados apenas no computador do dono do canal. Nada é enviado a servidores próprios, vendido ou compartilhado com terceiros. As estatísticas servem só para decidir quais formatos de vídeo o canal deve produzir.

4. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Depois disso, a ferramenta não consegue mais acessar o canal, e os dados guardados localmente podem ser apagados pelo dono do computador.

5. Serviços do Google

A ferramenta usa os Serviços de API do YouTube. Ao usá-la, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de dados do usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Privacy Policy (English)

Fábrica Arquivo Treze is a private desktop tool used only by the owner of the YouTube channel "Arquivo Treze". With the owner's authorization through Google sign-in, it uses YouTube API Services, only on the owner's own channel, to upload the channel's own videos (title, description, tags, scheduled publish time), upload their captions, add them to the channel's own playlists, and read the channel name and the statistics of the channel's own videos (views, likes, comments, retention, subscribers gained) through the YouTube Data API and the YouTube Analytics API.

It does not access data about individual viewers, other channels or other Google accounts. The Google access token and the statistics are stored only on the owner's computer; nothing is sent to other servers, sold or shared with third parties. Access can be revoked at any time at myaccount.google.com/permissions.

The tool uses YouTube API Services: by using it you also agree to the YouTube Terms of Service, and the Google Privacy Policy applies. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: artfbrand@gmail.com.
